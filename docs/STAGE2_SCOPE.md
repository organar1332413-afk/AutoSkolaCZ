# ЭТАП 2: реализованная область и принятые решения

Продолжение Stage 1 (`stage1-apk`, `59b2e95508a9a09e1a88e4a7a2c3b58599cddeca`). Архитектура из четырёх модулей сохранена: `app`, `core:domain`, `core:data`, `core:designsystem`. Jetpack Compose, MVVM, Room и DataStore остаются основой проекта.

## Аудитория и языки

- Единое приложение Autoškola CZ для чехов, русскоязычных и украиноязычных пользователей.
- Onboarding из трёх шагов: способ использования; независимые язык интерфейса и режим материала; уровень языковой поддержки.
- Пресеты: CZ only → CS UI; CZ+RU → RU UI; CZ+UK → UK UI. Далее настройки независимы.
- Главная адаптируется по режиму материала, а не по языку меню. CZ only скрывает центральную рекомендацию «Чешский для экзамена», вкладка слов становится повторением. Функция слов остаётся доступной по желанию.
- Beginner показывает перевод, Intermediate раскрывает его по запросу, Exam исключает переводы и словарные подсказки. Настоящий экзамен дополнительно запрещает подсказки независимо от настроек.
- CS — источник оригиналов, RU/UK — отдельные записи переводов. Добавление будущих языков не меняет модель официального вопроса.
- При отсутствии подтверждённого словарного значения можно сохранить исходную словоформу; приложение не придумывает перевод или лемматизацию.

## Учебный процесс

- Вопросы: все, ошибки, избранные, непройденные; выбор ответа, результат и доступное объяснение, ID/категория/баллы, соседние вопросы.
- Попытки идемпотентны по ID и сохраняются транзакционно вместе с прогрессом. Корректность вычисляет репозиторий из сохранённого официального ответа.
- Четыре причины ошибки сохраняются отдельно. Ошибки не исчезают от нескольких быстрых нажатий: освоение требует трёх правильных решений в разных сессиях с интервалом минимум 6 часов. Интервал — явное продуктовое решение этого этапа. Новая редакция вопроса начинает новый цикл повторения; история сохраняется.
- Словарь по нажатию работает на вопросе, ответах и текстах урока. Разбор фразы использует известные формы слов и не выдаёт предположения за проверенный перевод.
- «Мои слова»: сохранение, удаление, карточки повторения, число повторений и правильных ответов. Полноценный алгоритм интервального повторения пока не включён.
- TTS: установленный офлайн-голос чешского языка, скорости 1.0 и 0.7; обработка отсутствия голоса, остановка при уходе приложения в фон, освобождение движка.
- Уроки из Room: заголовок, короткое правило, ситуация, объяснение, источник, перевод, слова, практика, официальные вопросы, результат. Сохраняется позиция и завершение, главная предлагает продолжить незавершённый урок.
- Изображения вопроса/ответа загружаются из проверенного локального импорта (PNG/JPEG/WebP). Отсутствующее/неподдерживаемое медиа отображается как недоступное.
- Статистика рассчитывается из сохранённых попыток, экзаменов и слов. Демонстрационные попытки отделены от результатов по официальной полной базе. Субъективные причины ошибок не выдаются за измеренный уровень языка.

## ExamEngine

Domain-движок и Room-репозиторий: категория B; квоты 10/4/3/3/2/2/1; 25 уникальных вопросов; 30 минут; максимум 50; проходной балл 43. Требуются полная проверенная база, баллы, категория допуска B. Sample запрещён.

Сессия сохраняет версию базы, конкретные редакции вопросов, ответы и абсолютный deadline. Обновление активной базы не меняет начатый экзамен. Просроченный экзамен завершается при восстановлении; результат недоступен до завершения. Пропущенные ответы дают потерянные баллы и попадают в ошибки без выдуманного кода ответа.

Полный пользовательский интерфейс настоящего экзамена на этом этапе не включён. В поставляемом sample запуск заблокирован. Синтетические вопросы для проверки квот находятся только в тестах и не попадают в APK.

## Room и хранение

Room v1, ровно 29 таблиц. Identity hash: `81cbd33873aab63bc39ee4c31a037fe3`. Entity и экспортированная схема Stage 1 не менялись, миграция не требуется. Новые DAO/репозитории используют существующие таблицы; onboarding хранится в DataStore.

Нет регистрации, сервера, аналитики, рекламы, Billing, подписок, paywall и разрешения INTERNET. Прогресс локальный. Системное резервное копирование данных приложения отключено; внешняя копия проекта не содержит личный прогресс телефона.

## Граница сборок

DeveloperController, UI Developer Tools, сброс onboarding, sample bootstrap, демонстрационные JSON и ресурсы диагностики находятся в `src/debug`. В `src/release` — пустые точки подключения; production не содержит управляющих функций разработчика.

Инструменты debug: сброс onboarding; сброс прогресса; очистка попыток, избранного, слов; переключение UI/материала/уровня; версия схемы и контента; количество вопросов и completeForB; проверка TTS; открытие демонстрационного урока. Действия удаления требуют подтверждения на самом устройстве.

Debug имеет отдельный applicationId `cz.autoskola.study.debug`. Release — `cz.autoskola.study`, `debuggable=false`, без sample assets и без настройки production-подписи. Включён только обычный ключ разработки для обновления debug-установок с сохранением их данных.

## Состав контента и ограничения

1. Три неизменённых официальных sample-вопроса Stage 1: RP0604222, RP0606185, RP0605535. Для них не подтверждены баллы, полный допуск B и дата публикации полного банка; `sample=true`, `completeForB=false`. Русские/украинские переводы имеют статус draft.
2. Четыре исходные словарные записи Stage 1. Дальнейшее наполнение требует проверки контекстных значений, примеров и форм.
3. Один debug-урок из десяти блоков объясняет работу приложения. Он явно помечен как демонстрация и не выдаётся за урок ПДД.
4. Полный официальный банк, изображения знаков, юридически проверенные уроки и медицински проверенный курс первой помощи не добавлены. Разделы без контента показывают честные пустые состояния.
5. Нет автоматического обновления банка по сети. Существующий версионный импортёр сохраняет оригиналы и проверяет пакет/медиа; адаптер официального экспорта и механизм доверенной доставки обновлений требуют дальнейших официальных данных.
6. Видео/SVG и полная интерактивная визуализация дорожных ситуаций пока не воспроизводятся.
7. Озвучивание требует заранее установленного офлайн-чешского голоса Android. Приложение не скачивает голос автоматически.
8. Проверка на физическом телефоне и реального звучания TTS — отдельная проверка при установке. JVM-тесты и проверка APK не подменяют её.
9. Release собирается для проверки границы production, но ещё не предназначен для публикации в Google Play: нет полного контента и production-подписи.
